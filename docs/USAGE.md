## 快速开始

### 启动应用

安装完成后，启动Moraya：

- **Linux**: 运行 `moraya` 命令或点击应用图标
- **macOS**: 双击 `/Applications/Moraya.app`
- **Windows**: 双击桌面快捷方式或开始菜单图标

### 首次配置

1. **选择工作目录**
   - 侧边栏显示"打开文件夹"按钮
   - 选择一个Markdown文档目录
   - 推荐创建专门目录：`~/Documents/Markdown`

2. **创建第一个文档**
   - 侧边栏右键 → 新建文件
   - 输入文件名（如 `README.md`）
   - 自动打开编辑器

3. **开始编写**
   - 输入 `# Hello Moraya` 并按空格
   - 自动转换为一级标题
   - 继续编写正文内容

## 基础功能

### 文件管理

#### 创建文件

1. **新建Markdown文件**
   - 侧边栏右键 → 新建文件
   - 输入文件名（自动添加 `.md` 后缀）
   - 或快捷键：`Ctrl+N` / `Cmd+N`

2. **新建文件夹**
   - 侧边栏右键 → 新建文件夹
   - 输入文件夹名
   - 用于分类管理文档

#### 打开文件

1. **从侧边栏打开**
   - 单击文件名
   - 或双击文件名

2. **快速打开**
   - 快捷键：`Ctrl+P` / `Cmd+P`
   - 输入文件名搜索
   - 选择文件打开

3. **最近文件**
   - 文件菜单 → 最近文件
   - 快速访问最近编辑的文档

#### 文件操作

- **重命名**: 右键 → 重命名
- **删除**: 右键 → 删除（确认提示）
- **移动**: 拖拽文件到目标文件夹
- **复制**: 右键 → 复制
- **粘贴**: 右键 → 粘贴

#### 文件搜索

1. **全文搜索**
   - 快捷键：`Ctrl+Shift+F` / `Cmd+Shift+F`
   - 输入关键词
   - 显示匹配结果列表

2. **文件名搜索**
   - 侧边栏上方搜索框
   - 输入文件名
   - 过滤文件列表

### Markdown编辑

#### 基本语法

| Markdown语法 | 快捷方式 | 效果 |
|-------------|---------|------|
| `# 标题` | `Ctrl+1` | 一级标题 |

#### 列表

- **无序列表**: 输入 `- ` 或 `* ` 后按空格
- **有序列表**: 输入 `1. ` 后按空格
- **任务列表**: 输入 `- [ ] ` 或 `- [x] `

#### 表格

创建表格：

```markdown
| 列1 | 列2 | 列3 |
| --- | --- | --- |
| 内容1 | 内容2 | 内容3 |
```

操作：
- 点击表格 → 显示浮动工具栏
- 工具栏功能：插入行/列、删除行/列、对齐

#### 代码块

创建代码块：

```markdown
```javascript
function hello() {
  console.log('Hello Moraya');
}
```
```

操作：
- 输入 ````语言名` 后按回车
- 自动创建代码块
- 支持语法高亮（25+语言）
- 一键复制按钮

#### 数学公式

使用LaTeX语法：

- **行内公式**: `$E=mc^2$`
- **块级公式**: 
  ```markdown
  $$E=mc^2$$
  ```

示例：
- `$\frac{a}{b}$` → 分数
- `$\sqrt{x}$` → 根号
- `$\sum_{i=1}^n$` → 求和

### 编辑模式

#### Visual模式（所见即所得）

- **特点**: 类Word编辑体验
- **优点**: 直观、所见即所得
- **适合**: 新手用户、快速编辑

操作：
- 输入Markdown语法后按空格立即转换
- 支持富文本工具栏
- 拖拽图片直接插入

#### Source模式（源码）

- **特点**: 纯Markdown文本
- **优点**: 精确控制、适合复制粘贴
- **适合**: 高级用户、Markdown专家

操作：
- 显示原始Markdown代码
- 手动编写语法
- 支持语法高亮

#### Split模式（分屏）

- **特点**: 左侧源码、右侧预览
- **优点**: 实时对照、块级同步滚动
- **适合**: 学习Markdown、复杂排版

操作：
- 左侧编辑源码
- 右侧实时预览
- 滚动同步到对应段落

切换模式：
- 快捷键：`Ctrl+/` / `Cmd+/`
- 或点击编辑器右上角模式按钮

#### 图片操作

- **调整大小**: 点击图片拖拽边角
- **浮动工具栏**: 
  - 左对齐、居中、右对齐
  - 设置尺寸
  - 删除图片

- **右键菜单**:
  - 保存图片
  - 复制图片
  - 删除图片
  - 查看原图

#### 1. 打开AI设置

```bash
# 打开设置
Ctrl+, / Cmd+,

左侧菜单 → AI设置
```

#### 2. 选择AI Provider

支持的Provider：

| Provider | 特点 | API Key来源 |
|----------|------|-------------|
| **Claude** | 最新Claude 3.5，强推理 | [Anthropic](https://console.anthropic.com/) |

```bash

2. 输入API Key
3. 配置Base URL（可选）

5. 保存设置

- API Key存储在系统Keychain（安全）
- 不会明文保存到文件
- 仅通过Rust后端调用API

```bash

DeepSeek: deepseek-chat
Ollama: llama3.2, qwen2.5

Top P：0.1-1.0

## 飞书同步

### 功能概述

Moraya支持飞书云文档同步，实现：

- **本地Markdown编辑**
- **飞书云端存储**
- **双向同步**
- **多知识库管理**

### 前置要求

1. **安装lark-cli**
   - 参考 [lark-cli安装指南](./lark-cli-installation-guide.md)

2. **飞书账号**
   - 企业版或个人版
   - 有云文档权限

### KB绑定流程

#### 1. 打开KB管理器

```bash
# 点击侧边栏"知识库管理"按钮
# 或快捷键：Ctrl+Shift+K / Cmd+Shift+K
```

#### 2. 选择知识库

```bash
# 列表显示本地知识库
# 选择要绑定的KB
# 点击飞书图标按钮
```

#### 3. 配置绑定（4步流程）

**Step 1：配置lark-cli**
- 输入lark-cli路径（自动检测默认路径）
- 输入飞书文件夹Token（从URL提取）
- 选择同步模式（markdown/docs/drive）
- 点击"测试认证"验证

**Step 2：扫描文件**
- 自动扫描本地KB文件
- 自动扫描飞书云端文件
- 显示文件数量对比

**Step 3：选择策略**
- **上传到飞书**：本地覆盖云端
- **从飞书下载**：云端覆盖本地
- **仅绑定**：稍后手动同步
- 配置自动同步（可选）

**Step 4：执行同步**
- 显示同步进度
- 完成后显示结果（成功/失败文件数）

### 同步模式说明

#### Markdown模式（推荐）

- **特点**: 纯Markdown双向同步
- **优点**: 保持原始格式
- **适合**: 技术文档、笔记

#### Docs模式

- **特点**: 飞书富文本文档格式
- **优点**: 支持表格、图片、格式化
- **缺点**: 部分Markdown语法可能转换

#### Drive模式

- **特点**: Drive文件存储
- **优点**: 保持原样，不转换格式
- **适合**: 二进制文件、特殊格式

### 同步操作

#### 手动同步

```bash
# KB管理器 → 点击KB → 点击"立即同步"
# 或右键KB → 同步
```

#### 自动同步

```

### 同步状态

状态栏显示同步状态：

- **空闲**: 无同步任务
- **同步中**: 显示进度spinner
- **成功**: 显示成功图标
- **失败**: 显示错误图标
- **冲突**: 显示警告图标（数量）

### 常见问题

#### 1. 认证失败

**问题**: lark-cli认证失败

**解决**:
```bash
# 终端登录lark-cli
lark-cli auth login --domain markdown

# 重新测试认证
```

#### 2. folder-token无效

**问题**: 文件夹Token错误

**解决**:
```bash
# 检查Token格式（以fldcn开头）
# 确认有访问权限
# 尝试在浏览器打开文件夹URL
```

#### 3. 同步失败

**问题**: 文件同步失败

**解决**:
```bash
# 检查文件路径正确
# 确认文件是有效Markdown

## 常见问题

### 1. AI回复慢

**问题**: AI回复等待时间长

**解决**:
- 检查网络连接
- 使用更快的模型（如GPT-4o-mini）
- 使用本地模型（Ollama）
- 减少输出Token数量

### 2. 图片无法显示

**问题**: 插入的图片不显示

**解决**:
- 检查图片路径是否正确
- 确认图片文件在工作目录内
- 使用相对路径
- 重新插入图片

### 3. 导出PDF失败

**问题**: PDF导出错误

**解决**:
- 检查文档是否有复杂图表
- 简化Mermaid图表
- 减少图片数量
- 尝试HTML导出后再转PDF

### 4. 同步冲突

**问题**: 本地和云端都有修改

**解决**:
- 查看冲突提示
- 手动选择保留版本
- 或手动合并内容
- 未来版本将提供冲突对比UI

### 5. MCP工具调用失败

**问题**: AI无法调用MCP工具

**解决**:
- 检查MCP服务器运行状态
- 确认MCP配置正确
- 查看MCP日志
- 重新启动MCP容器

### 6. 快捷键不生效

**问题**: 快捷键无反应

**解决**:
- 检查快捷键冲突（其他应用占用）
- 查看设置中的快捷键配置
- 重启应用
- 检查键盘布局（中文输入法可能冲突）

### 7. 内存占用高

**问题**: 应用占用内存过大

**解决**:
- 关闭不需要的AI对话
- 清理历史快照
- 减少打开文件数量
- 禁用知识库索引（如不需要）

### 8. 找不到功能

**问题**: 某功能找不到入口

**解决**:
- 查看菜单栏（File/Edit/View/AI/Help）
- 使用命令面板（Ctrl+Shift+P）
- 查看快捷键列表
- 查阅Wiki文档

## 性能优化建议

### 提升编辑性能

- **减少打开文件数**: 关闭不需要的文件
- **简化大文档**: 分拆大型文档
- **禁用实时预览**: 使用Source模式
- **关闭自动保存**: 手动保存（Ctrl+S）

### 提升AI性能

- **使用本地模型**: Ollama无需网络
- **选择小模型**: llama3.2:1b, qwen2.5:0.5b
- **减少上下文**: 不要发送整个大文档
- **使用缓存**: AI设置中启用响应缓存

### 提升同步性能

- **增量同步**: 只同步修改的文件
- **减少文件数**: 合理分类KB
- **优化网络**: 使用稳定网络环境
- **调整间隔**: 增加自动同步间隔
